前言  

迈入互联网时代之时，著名的网络法律专家、被《商业周刊》称为「互联网时代的守护神」的 Lawrence Lessig 在其专著 《Code and other Laws of Cyberspace》中给出了互联网时代著名的论断 「Code is Law」，即无论是程式代码还是法律文典都是构成社会控制的规则工具。而在2021年，当我们身处一个高度数字化的时代，算法透过程式代码的实现，其本身已成为这个数字时代法则之网的编织物而无所不在。在这样一个新时代，似乎「Code is Law」真正即将实现，而其所带来的新问题是，究竟哪一项CODE更具有话语权？或者说CODE背后的制定者权力的博弈又将是如何的？  

****本期我们邀请了「文武双修」的上海交通大学凯原法学院博士研究生、上海交通大学中国法与社会研究院研究助理、人工智能与法律研究中心主任助理衣俊霖，和我们共同探讨算法技术标准对物理世界和虚拟世界「CODE is Law」的影响，以及多元参与主体间的权利平衡。****

**关于普通人的数字权利指北：**作为开放数据中国在「数字权利」工作板块下新开展的系列活动，《指北》旨在通过线上线下的讲座、圆桌、互动工作坊等面向普通市民科普大数据和人工智能正在如何影响每个普通人的生活，并逐步树立起自身数字权利意识，掌握如何通过既有的法律、政策等赋予的工具去主张自身的权益，并共同探索数字时代公民数字权利的新路径、新机制和新工具。
